# Contributing

Bounties in this repository are run with [GitHoney](https://githoney.io).

1. Find an issue labelled `githoney-bounty` and read its reward and deadline.
2. Accept it with `/githoney accept-bounty --bountyId <id> --address <your addr1…>` and sign the link the bot replies with.
3. Open a pull request whose description is `/githoney link-bounty --bountyId <id>`.
4. When a maintainer merges it before the deadline, the bot posts a link to claim the reward.
